# Bss

Описание формата Bss - v1

Данные хранятся в сжатом(gzip) файле в бинарном виде.

Формат описывает 1 том.

**Достоинства**

- описывается только 1 том, кол-во записей не так велико
- высокая степень компрессии - маленький размер тома

**Недостатки**

- поиск только в рамках 1 тома
- при обновлении - надо всё грузить в память

## Форматы данных

- uint8 - unsigned 1 byte(0-255)
- uint16 - unsigned 2 byte(0-65 535)
- uint32 - unsigned 4 byte(0-4 294 967 295)
- uint64 - unsigned 8 byte(0-18 446 744 073 709 551 615)

## Структура документа

Данные располагаются последовательно в определённых секциях.

```
[magic][format_description][volume_description][file_description]...[file_description][magic]
```

- magic [ulong 8] - идентификатор файла и метка контроля структуры
- format_description [ulong 8][ulong 8][ulong 8] - описание формата, резерв
- row_len [ushort 2] - длина данных структуры строки данных файла
- volume_description - структура описания тома, см. ниже
- file_description - структура описания файла, см. ниже

Чтение из файла производится последовательно, начиная с начала.

### magic

Идентификатор файла - заданная константа для проверки типа файла, также является идентификатором формата(с версией)

размер - 8 байт(uint64)

```
0xde9e4cee5e764387
```

для генерации

```bash
openssl rand -hex 8
```

### format_description

Описание формата, в данной версии просто резерв

размер - 24 байт

### volume_description

Содержит данные, описывающие свойства всего тома

**Структура**

```
[created][icon][records][name][scan_path][description]
```

- created [uint64] - дата создания(unix timestamp)
- records [uint64] - кол-во записей
- icon [uint16] - id иконки
- name [bin_str] - название тома
- scan_path [bin_str] - путь до ресурса сканирования
- description [bin_str] - произвольное описание

### file_description

Описание файла

**Структура**

```
[fid][pid][size][ctime][type][name]
```

- fid [uint64] - id записи
- pid [uint64] - id родителя(0 - корень)
- size [uint64] - размер файла
- ctime [uint64] - дата создания файла(unix timestamp)
- type [uint16] - тип файла(каталог - 0/файл - 1)
- name [bin_str] - название

### bin_str

Представление строки в бинарном виде

**Структура**

```
[str_len][string_bytes]
```

- str_len - uint16 - длина строки в байтах
- string_bytes - variable - сама строка в бинарном виде

## Порядок чтения

- Открыть файл на чтение
- Проверить magic
- Прочитать format_description, для данного варианта - резерв и не используется
- Прочитать последовательно volume_description и узнать кол-во записей
- Прочитать все записи последовательно по кол-ву записей из volume_description
- Проверить magic
