# DCat

Проект предназначен для сохранения структуры каталога или диска в локальной базе данных с последующим просмотром и навигацией.
Является представителем программ - каталогизаторов.

## Варианты

- **dcat** - оригинальная версия на python с хранением в sqlite
- **dcat_bss** - версия на python + PyQt5 для базы bss
- **dcat_mcsv** - версия на python + PyQt5 для базы mcsv
- **dcat_bss_go** - версия с базой BSS(один файл - один том) на go и UI GIO
- **dcat_bss_imgui** - версия с базой BSS(один файл - один том) на cpp и UI imgui
- **dcat_heap_example** - версия для экспериментов с heap-базой - python
- **dcat_heap_go_reader_example** - версия для экспериментов с heap-базой - go(только cli)
- **dcat_java** - версия на java + swing с хранением в sqlite

## Другие проекты и ответвления

- [JDCat](https://github.com/sysdeep/jdcat) - проект на Qt с базой в виде json
- [QDCat](https://gitlab.com/sysdeep/qdcat) - проект на Qt с поддержкой оригинального хранилища dcat

## Варианты хранения

- multi volume sqlite - оригинальный формат на базе sqlite с несколькими томами
- bss - формат хранения 1 тома в бинарном виде с gzip компрессией

### Различия и поиски

Вариант с несколькими томами разрабатывался с учётом поиска по томам, но в связи с необходимостью хранить все тома - размер базы большой и как следствие - чем больше - тем накладнее читать и содержать. С другой стороны, форматы с 1 томом более легковесные, но не имеют возможности поиска.
